# 别墅解救平民场景设计

> 当前修订：按最新反馈缩小别墅，增加右下角大门和四侧窗户。僵尸从地图边缘生成，破门、破窗后进入；六名平民统一改为蓝色。此修订替代早期“无门窗、整面墙受击形成缺口、绿色平民”的方案。

## 1. 目标

六名平民固定留在中央，七名士兵开局直接环绕平民保护。僵尸从地图四边连续生成，接近门窗并攻击，破坏后从该开口进入别墅。内部没有房间隔断或其他障碍。

- 平民不移动、不攻击、不接受玩家指令，也不会被推离初始位置。
- 正常平民统一为蓝色 `#4BA3FF`，浅蓝描边，使用无武器的人形标记。
- 士兵为四名步枪兵、两名喷火兵、一名盾兵；玩家可按现有规则拖拽调整。
- 平民首次受到有效僵尸攻击后原地变身，模拟时间达到 `0.8s` 后成为一只普通僵尸，立即失败。
- 达到 `240` 只生成上限后停止生成；场上僵尸全部消灭、六名平民均正常时获胜。
- 不使用波次，不加入评分、星级、排行榜、伤亡或用时评级。

## 4. 连续生成与进屋

初始间隔 `0.60s`，在 `60s` 内平滑缩短至 `0.20s`，当前单次生成一只普通僵尸，四侧均衡，总计 `240` 只。相较上一版 `1.20s → 0.45s / 120s`，开场生成速度翻倍，并更早达到高压节奏。参数统一维护在本场景 JSON 的 `level.continuousSpawn`，出生区域维护在 `map.spawnPoints`。没有波次开始、波次等待和“第几波”文案。

| 侧面 | 固定出生条带 |
|---|---|
| 北 | `x=92..988, y=204..228` |
| 东 | `x=972..996, y=260..2080` |
| 南 | `x=92..988, y=2112..2136` |
| 西 | `x=84..108, y=260..2080` |

条带中的槽位循环复用，后续生成不能逐排向室内推进。每次出生均位于墙外，不借助碰撞纠正把新僵尸挪进别墅。

僵尸寻路规划可以经过门窗，但移动碰撞仍阻止穿过完整门窗。靠近后累计攻击间隔、扣除对应门窗耐久；耐久归零时只开放此门窗的通道。剩余墙段和四角持续阻挡。进入后寻找最近平民；近战范围内有士兵拦截时先与士兵交战。僵尸不能隔墙命中平民。

## 5. 平民状态与结算

`正常 → 首次有效攻击 → 原地变身 0.8s → 普通僵尸 + 解救失败`。

变身时显示暗蓝闪烁和进度条；暂停冻结计时；重复攻击不重复创建变身。完成时隐藏原平民，使用普通僵尸视图接管。即使最后一只外来僵尸同时被消灭，也不能取消已经开始的变身或提前胜利。

HUD 显示 `平民：6/6`、各方向门窗状况和僵尸生成数量。结算只显示“6 名平民成功获救”或“平民被感染，解救失败”，不展示击杀评分或士兵存活评价。重新开始后六名蓝色平民、七名士兵、全部门窗和生成器恢复初始状态。

## 6. 验收重点

1. 开局能看到六名蓝色平民和环绕的七名士兵。
2. 别墅明显缩小，右下角大门和四侧窗户可辨认。
3. 所有僵尸从外围条带生成，后期不会出生在室内或卡进墙中。
4. 北、东、西来向能破窗进入；南侧来向可以破南窗或右下角大门进入。
5. 门窗完整时阻止身体穿越，破坏后通行，旁边墙体不消失。
6. 平民固定、可被进屋僵尸攻击、0.8 秒后变成普通僵尸并失败。
7. 连续生成结束并清场后成功，暂停、重启和旧场景正常。
