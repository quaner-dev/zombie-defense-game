# 游戏灵感记录

用于记录僵尸防御微信小游戏的后续想法，不作为已批准需求或开发任务。

## 记录约定

- 当前只做记录，不进行开发、代码修改、自动排期或定时提醒。
- 保留用户想法原意，不擅自补充玩法、数值、实现方案或验收要求。
- 后续用户索要时，提供完整列表或指定条目；细化和开发由用户后续决定，当前由用户自行负责。
- 每条灵感使用稳定编号 IDEA-001、IDEA-002……，便于后续补充与引用。
- 仅在用户明确要求时，把灵感转为细化需求或开发任务。

## 灵感列表

### IDEA-001：可自由查看与分区切换的大地图生存模式

状态：仅记录，未细化、未安排开发。

- 后续可增加一种模式，地图布局固定，但扩大范围，不再局限于当前单屏战场。
- 视角由玩家控制，不始终锁定或自动跟随小队；玩家可以拖动地图查看其他位置，小队仍留在原处，拖动视角不等于命令小队移动。
- 提供“回到小队附近”入口，点击后镜头切回以小队位置为中心的视角；不预设此后持续锁定跟随。
- 地图可以划分为 A区、B区、C区等不同小区域，玩家可以切换查看不同区域；区域切换的具体交互留待细化。
- 玩家可以另外指挥士兵移动到地图上的某个位置；具体移动操作留待细化。
- 僵尸在小队周围不断生成，形成持续的生存压力。
- 体验参考用户提到的“吸血鬼那个游戏”，可能指《吸血鬼幸存者》，具体名称未确认；仅记录该方向，不自动引入其升级、装备等其他机制。
- 后续重新设计一张更大的地图，支持小队在其中移动。

更正：此前“以小队为视角中心、画面随小队移动”的表述不准确，现以玩家自由控制视角、可主动回到小队及分区切换为准。“玩家视角”不自动解释为新增可操控的玩家角色或第一人称模式。

### IDEA-002：可选地图的无尽坚持模式

状态：仅记录，未细化、未安排开发。

- 增加无尽模式，支持选择地图。
- 用户记得现有内容中有一个演示模式或测试模式，考虑以该模式为基础改成无尽模式；具体指哪个模式尚未确认，此处不视为已核实的代码现状。
- 玩法重点是长时间坚持、生存，看看能坚持多久；具体结束条件与评价方式留待细化。
- 用户已澄清此前“动态添加识别”指的是在无尽模式过程中动态调整兵力，包括生成、补充士兵，不是敌人识别机制。
- 兵力生成形式可考虑空降，或类似“小球分裂”的形式；两者都是候选想法，尚未选定，也不要求同时实现。
- 具体补兵触发条件、频率、数量，以及“小球分裂”的具体规则留待后续细化，不擅自补充。

原话备注：同一段话先明确说“无尽模式”，后出现“五金模式”，结合上下文记录为无尽模式。
