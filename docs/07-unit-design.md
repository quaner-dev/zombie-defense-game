# 兵种与僵尸设计（MVP 及后期扩展 v1.0）

> 目的：定义单位职责、状态、行为边界和扩展方法。
> 当前 MVP：步枪兵、喷火兵、盾兵与普通僵尸；总人数和武器参数见本文末的当前规则。
> 具体数值见 `08-combat-numeric-model.md`。

## 1. 设计原则

1. 单位行为由组件负责表达，战斗结算由系统统一处理。
2. 单位类型通过配置 ID 区分，核心系统不依赖具体类名。
3. MVP 只实现必要状态；后期状态必须能在不改波次和地图接口的情况下增加。
4. 玩家以单兵微操调度队伍，单位仍由核心系统自动寻敌和战斗。

## 2. 单位公共模型

每个单位至少包含：

- `unit_id`：运行时唯一 ID。
- `unit_type`：如 `rifleman`、`normal_zombie`。
- `faction`：`human` 或 `zombie`。
- `position`、`velocity`：地图逻辑坐标和移动速度。
- `hp`、`max_hp`：当前生命和最大生命。
- `state`：当前行为状态。
- `route_id`：生成时的路线；当前 headless MVP 移动后保持原路线，用于可重复的兵群归属。
- `target_id`：当前攻击目标，没有目标时为空。

## 3. 步枪兵 rifleman

### 职责

远程输出和路线增援单位。步枪兵在射程内自动寻找普通僵尸并开火；玩家可以单独移动士兵改变其射击位置。

### MVP 状态

- `Idle`：静止，没有可攻击目标。
- `Moving`：正在执行移动指令，同时保持自动索敌和攻击。
- `Aiming`：已有有效目标，等待攻击间隔。
- `Firing`：创建一条子弹轨迹并提交命中事件。
- `Dead`：停止移动、攻击和选择，等待对象池回收。

### 行为边界

- 玩家可以单独选中并移动存活士兵。
- 多个步枪兵可以攻击同一个僵尸。
- 步枪兵移动期间继续产生攻击；到达目标点后继续自动索敌。
- 步枪兵死亡后不参与人数统计、索敌和移动指令。

## 4. 普通僵尸 normal_zombie

### 职责

出生即寻找可达的存活士兵追击；遇墙沿墙角寻路，路线被关闭的房门挡住时先攻击门，再进入房间近身攻击。

### MVP 状态

- `Advancing`：未跨线时追击最近士兵。
- `Breached`：历史上已跨线的追击状态；可返回线上方。
- `Attacking`：在近身范围内按攻击间隔扣血。
- `Dead`：停止行为，等待对象池回收。

### 行为边界

- 无论是否跨线，进入28px近身范围均可攻击。
- 越过防线后 `breached` 为永久标记，但可以追击防线以上的步枪兵并近身攻击；旧“不再回到防线以上”限制废止。
- 目标选择为最近的可达存活士兵；目标不可达时尝试其他可达目标。
- 不实现特殊技能、远程攻击、分裂、加速和精英属性。

## 5. 未来单位扩展

后续新增单位应通过“配置 + 行为组件 + 视觉预制体”扩展：

| 类型 | 示例 | 新增能力 |
|---|---|---|
| 远程人类 | `sniper` | 更长射程、更长攻击间隔、更高伤害 |
| 远程人类 | `sniper` | 更长射程、更长攻击间隔、更高伤害 |
| 特殊僵尸 | `runner` | 更高移速 |
| 坦克僵尸 | `tank_zombie` | 更高生命和更慢移速 |

新增类型必须明确：目标选择规则、攻击形式、受击规则、死亡规则、是否能越过防线，以及是否需要独立测试。

## 6. 状态转换约束

```text
步枪兵：Idle ↔ Moving → Aiming → Firing → Aiming
                         ↘ Idle
任意存活状态 → Dead

僵尸：Advancing/Breached ↔ Attacking（跨线标记独立于攻击资格）
任意存活状态 → Dead
```

- 状态转换由单位状态机发起，伤害和死亡由 `CombatSystem` 确认。
- 死亡是终态；对象池复用时必须完整重置 HP、目标、状态和位置。
- 视觉状态必须订阅状态变化，不能通过轮询猜测单位行为。

## 当前 MVP 规则

当前小队共 **7 名士兵**：4 名步枪兵、2 名喷火兵、1 名盾兵。车辆尚未加入当前场景；后续可按 MPV 坐 7 人的编成另行设计。玩家每次选中并移动一名士兵，自动索敌和战斗由核心处理。

步枪兵为 100 HP、30 点单发伤害、260px 射程、0.35s 攻击间隔、48px/s 移速。普通僵尸为 60 HP、10 点近战伤害、28px 近战距离、0.13s 攻击间隔、41.9px/s 移速。喷火兵以 190px 射程喷射，每次启动持续 0.6s、每 0.1s 造成一次 24 点范围伤害，范围半径 72px；表现层绘制火焰轨迹和命中特效。盾兵为近战攻击目标。普通枪弹和喷火伤害均由核心结算，不由表现层决定。

第一关是一座完整大屋，外围墙体围住连通大厅，南北各有一扇可破坏大门，每扇600 HP。僵尸每50ms逻辑步重新寻找可达的存活士兵；无墙阻挡时直线移动，遇墙使用墙角可见图绕行，抵达拦路大门后先攻击，门毁后再进入大厅。不可达目标会被其他可达目标替代；目标贴墙时使用可行走接近点。楼下场景没有可破坏房门，保留四块建筑之间的通道。

大屋僵尸从北、南入口生成，三波于0/7/20s开始，每波100/200/400只。楼下僵尸从地图北、南、东、西四边生成，三波于0/14/30s开始，每波60/90/120只。两场景均每批10只、间隔0.5s；波次不等待上一波清场。墙边达到3只时可堆叠翻越，翻越时避免分离推力，落地后再恢复单位间距。

A/B/C 只是分组与统计标签，不是僵尸固定路线。防线 y=1200 只用于首次越线警告，不是近战伤害门槛；僵尸与目标距离不超过28px且无墙体阻挡时即可攻击。当前规则与数值的自动化证据见 [验收报告](testing/mvp-test-report.json)，编辑器、构建和设备表现见 [Cocos手测](testing/cocos-manual-checklist.md)，尚未完成人工验收的项目保持未验证。
