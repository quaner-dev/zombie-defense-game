# 兵种与僵尸设计（MVP 及后期扩展 v1.0）

> 目的：定义单位职责、状态、行为边界和扩展方法。
> MVP：1 种人类单位步枪兵 + 1 种僵尸普通僵尸。
> 具体数值见 `08-combat-numeric-model.md`。

## 1. 设计原则

1. 单位行为由组件负责表达，战斗结算由系统统一处理。
2. 单位类型通过配置 ID 区分，核心系统不依赖具体类名。
3. MVP 只实现必要状态；后期状态必须能在不改波次和地图接口的情况下增加。
4. 玩家控制兵群，不直接控制单个单位。

## 2. 单位公共模型

每个单位至少包含：

- `unit_id`：运行时唯一 ID。
- `unit_type`：如 `rifleman`、`normal_zombie`。
- `faction`：`human` 或 `zombie`。
- `position`、`velocity`：地图逻辑坐标和移动速度。
- `hp`、`max_hp`：当前生命和最大生命。
- `state`：当前行为状态。
- `route_id`：生成时的路线；当前 headless MVP 移动后保持原路线，用于可重复的兵群归属。
- `target_id`：当前攻击目标，没有目标时为空。

## 3. 步枪兵 rifleman

### 职责

远程输出和路线增援单位。步枪兵在射程内自动寻找普通僵尸并开火；玩家可以单独移动士兵改变其射击位置。

### MVP 状态

- `Idle`：静止，没有可攻击目标。
- `Moving`：正在执行移动指令，同时保持自动索敌和攻击。
- `Aiming`：已有有效目标，等待攻击间隔。
- `Firing`：创建一条子弹轨迹并提交命中事件。
- `Dead`：停止移动、攻击和选择，等待对象池回收。

### 行为边界

- 玩家可以单独选中并移动存活士兵。
- 多个步枪兵可以攻击同一个僵尸。
- 步枪兵移动期间继续产生攻击；到达目标点后继续自动索敌。
- 步枪兵死亡后不参与人数统计、索敌和移动指令。

## 4. 普通僵尸 normal_zombie

### 职责

出生即寻找全场最近士兵，直线追击并在近身范围攻击。

### MVP 状态

- `Advancing`：未跨线时追击最近士兵。
- `Breached`：历史上已跨线的追击状态；可返回线上方。
- `Attacking`：在近身范围内按攻击间隔扣血。
- `Dead`：停止行为，等待对象池回收。

### 行为边界

- 无论是否跨线，进入28px近身范围均可攻击。
- 越过防线后 `breached` 为永久标记，但可以追击防线以上的步枪兵并近身攻击；旧“不再回到防线以上”限制废止。
- 目标选择为最近的存活步枪兵。
- 不实现特殊技能、远程攻击、分裂、加速和精英属性。

## 5. 未来单位扩展

后续新增单位应通过“配置 + 行为组件 + 视觉预制体”扩展：

| 类型 | 示例 | 新增能力 |
|---|---|---|
| 远程人类 | `sniper` | 更长射程、更长攻击间隔、更高伤害 |
| 防御人类 | `shield` | 近战减伤或阻挡 |
| 范围人类 | `flamethrower` | 范围伤害和持续效果 |
| 特殊僵尸 | `runner` | 更高移速 |
| 坦克僵尸 | `tank_zombie` | 更高生命和更慢移速 |

新增类型必须明确：目标选择规则、攻击形式、受击规则、死亡规则、是否能越过防线，以及是否需要独立测试。

## 6. 状态转换约束

```text
步枪兵：Idle ↔ Moving → Aiming → Firing → Aiming
                         ↘ Idle
任意存活状态 → Dead

僵尸：Advancing/Breached ↔ Attacking（跨线标记独立于攻击资格）
任意存活状态 → Dead
```

- 状态转换由单位状态机发起，伤害和死亡由 `CombatSystem` 确认。
- 死亡是终态；对象池复用时必须完整重置 HP、目标、状态和位置。
- 视觉状态必须订阅状态变化，不能通过轮询猜测单位行为。

## MVP follow-up：当前规则与校准

A/B/C、左中右仅为出生区域和统计标签，不是固定路径。僵尸出生即在全场选择最近存活士兵，每个 50ms 逻辑步重新决策，同距按稳定 ID；无障碍空间内直线追击，未实现 A*、导航网格或绕墙。距离 <=28px 即可近战，防线 y=1200 只记录首次跨线警告，不是伤害门槛，也不改变速度、伤害或防御；追击可返回线上方。

当前配置：最多 **15 名士兵**，初始编成为步枪兵、喷火兵和盾兵；普通僵尸速度 **41.9px/s**、60HP、攻击间隔 **0.13s**。步枪兵单发 **30** 点伤害、0.35s一发、260px射程；士兵与僵尸的显示直径分别为28px和32px。僵尸三波共350只，按每批5只、每秒一批从地图边缘进入；单位不会因新波次开始而重置。

当前自动化实测：挂机种子1..10均在79.95s胜利，15名士兵存活、0只僵尸；开局单兵微操场景108.85s胜利，14名士兵存活。完整状态和事件在不同帧分段下保持一致；真实 Cocos、触控和设备表现仍以手测清单为准。

MVP强制3秒自动布阵，无跳过入口；endDeployment仅为内部测试工具。可选微信短振动已实现，同批跨线合并且至少1000ms限频；无能力/抛错/异步失败不阻断战斗，暂停后台不补播、重开重置，物理效果未验证。墙侧阴影与复杂场景经用户确认延期；不扩展其他视觉功能。卡顿策略暂保留，待用户Cocos反馈再决定。Creator导入/真实渲染/构建、手机触控/振动/FPS/内存仍待用户手测，GitHub/许可证/发布暂缓。
