# 用户Cocos手测清单与记录模板

状态：**待用户执行，未进行Creator/构建/手机验收**。自动化cc替身、类型检查和bundle不是实际渲染/触控/物理振动证据。

## 操作准备

1. 在完整源码目录运行 `npm ci`、`npm run sync:core`；用Creator **3.8.8** 导入，等待AssetDB完成，打开并保存 `assets/scenes/Battle.scene`。
2. 选择Current Scene → Play，保留导入/运行控制台。确认1080×2400完整战场和安全区；错误先记录原文，再判断通过。
3. 微信真机另需本地合法AppID、Creator WeChat Mini Game构建、开发者工具导入及设备预览。发布操作、许可证及GitHub仍延期。
