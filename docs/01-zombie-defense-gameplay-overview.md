# 玩法设计总纲（终版 v1.0）

> 历史玩法规格：本文描述原型目标，不作为当前行为说明。现版七人队伍、喷火范围攻击、走廊房门、墙角寻路和尸潮数量见 [实际架构](architecture.md)、[故事场景](10-story-scenes-design.md) 与 [验证记录](testing/scenes-test-report.md)；Creator 与设备验收仍待完成。

> 定位：微信小游戏（game 类目）· 单机 · 实时指挥 · 波次防守
> 原型来源：B站视频《50步枪兵 VS 3波僵尸》（BV1YTp362EkH，作者：这球有问题，EP03）
> 状态：**终版**（评审决策已全部合入）
> 配套文档：02 数值与平衡设计 / 03 测试关卡文档 / 04 微信小游戏技术方案 / 05 视觉风格设计

## 1. 一句话定义

玩家用手指实时调度一支步枪兵兵团，在多路尸潮中分配火力、调防补位、守住防线直至最后一波。

## 2. 核心体验目标

| 目标 | 说明 |
|---|---|
| 指挥感 | 手指所及，兵之所往；调动兵团改变战局 |
| 紧张感 | 多路出怪，永远不够兵，必须取舍 |
| 复玩欲 | 每局随机事件不同，阵容成长不同，结果可比较 |

## 3. 玩法类型

- 主类型：**实时战术指挥**（Real-Time Tactics，RTT）
- 交互形态：触屏全局调度（兵团长调度，非单兵微操、非英雄操作）
- 视角：俯视战场，竖向地图（复刻原作 1080×2400 竖屏比例，适配手机）

## 4. 核心玩法循环

```
感知威胁（哪路僵尸多/快）→ 手指调度（点到兵群→拖到目标点）→ 战斗反馈（击杀/掉血/破门）→ 波次推进 → 结算 → 再来
```

- 单个循环时长目标：40~90 秒（复刻原作 42 秒节奏）
- MVP 波次按布阵结束后的战斗计时固定触发：0s / 7s / 20s，布阵倒计时期间不出怪且不计入战斗时间；地图保留左、中、右三个出生区域（不是固定路径），详见 `06-map-design.md`。
- 玩家每局核心决策：**往哪路增援、何时后撤重组**
- 集火由 AI 自动决策（MVP 按距离最近选择目标，规则见 08），玩家不做手动集火——避免微操

## 5. 触屏指挥交互设计

| 手势 | 功能 | 备注 |
|---|---|---|
| 单指点击 | 选中点击点附近的整个兵群，显示其状态 | 误触需有二次确认（指令箭头） |
| 单指拖拽（起手兵群） | 选中该处兵群 → 拖到目标点下达移动 | 核心操作，需手感调优 |
| 单指拖拽（起手空白） | MVP 不启用 | 不做空白框选 |
| 双指缩放/平移 | MVP 不启用 | 完整竖屏战场固定可视 |

> 集火策略：由程序 AI 自动决策（就近索敌 + 威胁优先级），玩家不手动点选目标；无集火消耗（不设能量成本）。

**交互原则**：
1. 移动指令用"箭头+路径预览"（规范见 05 §5），松手即执行，可滑动取消（拖回原点）；
2. 战斗中随时可下指令，不暂停（保持实时紧张感）；
3. 手机竖屏单手可玩，UI 拇指热区布局。

## 6. 界面与 HUD

```
┌─────────────────────────┐
│  50步枪兵 VS 3波僵尸      │  ← 顶部标题（可换地图名）
├─────────────────────────┤
│                         │
│      战场（俯视）          │  ← 绿色=人类 紫色=僵尸
│      多路通道             │
│                         │
├─────────────────────────┤
│ 步枪兵 50 │ 僵尸潮 第2/3波 │  ← 底部信息条
│ 人类 50   僵尸 83  ▓▓▓░░  │  ← 数量对比进度条
│ [暂停]                    │  ← 指令按钮
└─────────────────────────┘
```

- 波次提示：每波出怪时用大字横幅「第X波来袭」
- 破门状态：视觉警示 + 可选限频短振动（音效不在MVP）
- 胜负结算：全屏面板「僵尸占领 / 防线失守」「本局用时」+ 统计（简单版，无指挥评分）

## 7. 状态流程

```
开局布阵(强制,3s) → 战斗计时0s出怪 → 战斗计时7s出怪 → 战斗计时20s出怪 → 结算 → 再来
```

> 布阵阶段：开局 3 秒内玩家**点哪移哪**——手指点到某处即选中该处附近的兵群，拖动到目标位置/阵地，松手部署；可多次调整，倒计时结束自动开战。手机屏幕小，布阵不采用框选。

## 8. 复玩引擎（三支柱，MVP 后接入）

| 支柱 | 内容 | 阶段 |
|---|---|---|
| 随机事件 | 每局随机出现：尸潮变异（加速/厚血）、空投增援、天气（迷雾视野） | 单关内生效 |
| 兵种解锁成长 | 完成目标解锁新兵种（狙击手/盾兵/喷火兵），局外升级 | 多局积累 |
| 数值爬塔 | 地图推进 + 星级评价（无伤/速通/全歼），解锁下一地图 | 多局积累 |

## 9. 扩展预留（架构约束）

- **地图系统**：关卡 = 独立地图配置（路线/出生点/防线）+ 波次表 + 兵种阵容，新地图不改战斗内核；
- **兵种系统**：单位属性模板化（HP/攻/射程/移速/造价），新兵种即新配置；
- **模式预留**：无尽模式 = 波次表程序化生成；
- **数据驱动**：所有数值进 JSON 配置，不写死在代码中。

## 10. MVP 范围（第一期）

只做：1 张左中右三路地图（复刻50步枪兵vs3波僵尸）、1 种兵（步枪兵）、1 种普通僵尸、固定时间出怪、开局布阵、实时群体调度、子弹轨迹、简化破门和简单胜负结算。不做：成长、随机事件、多兵种、精英僵尸、空白框选、指挥评分、音效（可后补）。
