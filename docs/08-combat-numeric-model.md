# 战斗与数值模型（MVP v1.0）

> 目的：提供可直接实现、可重复测试的默认战斗规则。
> 单位设计和状态边界见 `07-unit-design.md`。
> 原则：先保证实时群体指挥和原作压力节奏，再通过配置调平衡。

## 1. 默认单位数值

| 属性 | 步枪兵 | 普通僵尸 |
|---|---:|---:|
| `max_hp` | 100 | 40 |
| `damage` | 10 | 10 |
| `attack_interval_s` | 0.5 | 1.0 |
| `attack_range_px` | 300 | 28 |
| `move_speed_px_s` | 120 | 60 |
| `collision_radius_px` | 7 | 8 |
| `target_limit` | 1 | 1 |

- 步枪兵理论射速为每秒 2 发，单发伤害 10。
- 普通僵尸每秒最多进行一次近身攻击。
- 初版攻击伤害不使用随机数，不产生暴击，不使用护甲。

## 2. 时间与更新

- 游戏逻辑以引擎 `update(deltaTime)` 驱动。
- `deltaTime` 限制在 `0..0.05s`；超过 50ms 的帧按 50ms 计算，避免单帧跳过多个状态。
- 攻击计时器使用累计时间，达到攻击间隔后执行一次攻击并扣除一个间隔。
- 单帧最多处理一次同一单位的攻击，避免低帧时瞬间连击。
- 伤害、死亡和胜负判定由 `CombatSystem` 按固定顺序处理：攻击事件 → 伤害 → 死亡回收 → 胜负检查。

## 3. 步枪兵索敌与攻击

1. 仅 `Idle` 或 `Aiming` 状态的步枪兵可以攻击。
2. 查询攻击范围内所有存活普通僵尸。
3. 目标按“距离最近”排序；距离相同按 `unit_id` 稳定排序。
4. 目标无效、死亡或离开射程时重新索敌。
5. 到达攻击间隔后创建一条子弹轨迹，轨迹命中后才提交伤害事件。
6. 步枪兵移动状态不索敌、不发射子弹；移动结束后重新开始索敌。

## 4. 子弹轨迹

子弹是表现对象，不是独立战斗单位，不参与碰撞查询和单位数量统计。

### 发射与命中

- 发射点：步枪兵当前地图坐标。
- 目标点：发射瞬间目标的当前坐标。
- 轨迹：从发射点到目标点的直线插值。
- 飞行速度：`900px/s`。
- 最大飞行时间：`0.35s`。
- 命中判定：到达目标点，或飞行时间达到最大值时命中。
- 命中时再次确认目标仍存活；若目标已死亡，子弹只播放到达效果，不产生伤害。
- 子弹表现建议使用对象池、短线段或细小精灵，颜色为柔和亮白/浅青。
- 同一发子弹只产生一次命中事件。

### 轨迹视觉

- 普通子弹轨迹持续约 `0.05~0.12s`，不要使用瞬时连线代替。
- 起点到目标点可有轻微透明度衰减，命中时显示小型亮点。
- 子弹轨迹不应遮挡单位主体；渲染层低于 HUD、高于单位或作为单位子层。
- 子弹池容量建议初始 `64`，达到上限时优先回收最早完成的表现对象，不影响伤害事件。

## 5. 僵尸移动与近身攻击

1. 僵尸从对应路线出生点向防线移动。
2. `position.y >= defense_line_y` 时标记为 `Breached`，只触发一次破门事件。
3. `Breached` 状态查询最近的存活步枪兵作为目标。
4. 僵尸与目标距离 `<= 28px` 时停止移动并进入 `Attacking`。
5. 达到 `1.0s` 攻击间隔后直接对目标扣除 10 HP。
6. 目标死亡或距离超过范围时重新选择目标并继续移动。
7. 破门不增加僵尸移速，不降低人类防御，不叠加额外伤害。

## 6. 群体移动

- 玩家指令选择点击点半径 `72px` 内、且未死亡的步枪兵。
- 一次指令产生一个 `MoveGroupCommand`，包含单位 ID 列表、目标点和发出时间。
- 每个单位向目标点附近的稳定编队位置移动，避免所有单位重叠在同一点。
- 移动速度使用单位 `move_speed_px_s`；到达距离 `<= 12px` 时视为到达。
- 新指令覆盖旧指令；移动中的单位不攻击。
- 无法选择到单位时不产生指令，也不改变当前战斗状态。

## 7. 胜负规则

- 所有波次均已生成且存活僵尸数为 0：胜利。
- 存活步枪兵数为 0：失败。
- 同一帧同时满足两者时，优先判定失败，避免玩家全灭后显示胜利。
- 结算触发后停止生成、移动、攻击和伤害，保留结算界面需要的统计快照。

## 8. 推荐配置结构

```json
{
  "units": {
    "rifleman": {
      "max_hp": 100,
      "damage": 10,
      "attack_interval_s": 0.5,
      "attack_range_px": 300,
      "move_speed_px_s": 120
    },
    "normal_zombie": {
      "max_hp": 40,
      "damage": 10,
      "attack_interval_s": 1.0,
      "attack_range_px": 28,
      "move_speed_px_s": 60
    }
  },
  "projectile": {
    "speed_px_s": 900,
    "max_flight_time_s": 0.35,
    "pool_capacity": 64
  },
  "movement": {
    "selection_radius_px": 72,
    "arrival_tolerance_px": 12
  }
}
```

## 9. 首轮调参顺序

1. 先调僵尸生命值和步枪兵射程，使前两波在挂机时基本无损。
2. 再调僵尸移速和防线距离，使第 3 波在约 25~35 秒开始造成减员。
3. 最后调僵尸近身攻击间隔和伤害，使挂机在约 38~50 秒内失败。
4. 子弹速度只影响观感和响应，不用于弥补战斗数值问题。
