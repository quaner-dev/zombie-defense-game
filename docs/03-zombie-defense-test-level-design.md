# 测试关卡文档：50步枪兵 VS 3波僵尸（终版 v1.0）

> 关卡名：`LV01_zombie_wave`（复刻测试关）
> 目的：验证核心玩法（实时指挥）手感 + 复刻原作数值节奏
> 验收：见 §6，全部通过即进入下一阶段
> 状态：**MVP 开发规格**（固定时间出怪、三路、普通僵尸、群体移动、子弹轨迹、简化破门）

---

## 1. 关卡目标

玩家指挥 50 名步枪兵，在 3 波尸潮（50/100/200）中守住防线。
- 新手目标：学会开局布阵（点哪移哪）、拖拽调度
- 进阶目标：无损通关
- 隐藏目标：指挥 50 兵全歼 350 僵尸（含第3波）

> 集火由 AI 自动决策，玩家不手动集火；开局强制布阵 3s。

## 3. 波次配置

| 波次 | 数量 | 分路 | 刷新时刻 | 特殊规则 |
|---|---|---|---|---|
| 第1波 | 50 | 全从中路(B) | 战斗计时0s | 教学波：提示"点到兵群→拖拽调度" |
| 第2波 | 100 | 左50 + 右50 | 战斗计时7s | 教学点：多路抉择 |
| 第3波 | 200 | 左60 + 中80 + 右60 | 战斗计时20s | 触发破门机制；全部普通僵尸 |

> 布阵倒计时结束后开始战斗计时；刷怪时刻为战斗计时 0s / 7s / 20s，不等待上一波清完。
> 开局：强制布阵 3 秒倒计时。**点哪移哪**：手指点到某处即选中该处附近的兵群，拖到目标位置/阵地松手部署，可多次调整；倒计时结束开战。

## 4. 破门机制

- 触发：任意僵尸坐标 `y >= defense_line_y`；
- 效果：触发一次破门视觉警告，僵尸继续接近步枪兵；
- 近身：与步枪兵距离 `<=28px` 后按固定攻击间隔直接扣血；
- 不做防御系数、冲击状态、额外速度、额外伤害和解除条件。

## 5. 教学引导（首局强制）

| 时机 | 引导 |
|---|---|
| 开局 | 文字气泡："手指点到兵群，拖到阵地（点哪移哪），倒计时结束开战" |
| 布阵倒计时 | 提示："剩余 X 秒，可继续调整兵力" |
| 第1波 | 提示："点到你的步枪兵，拖到目标位置" |
| 第2波 | 提示："左右都有僵尸，判断哪路更危险" |
| 第3波破门 | 红字警告："防线被突破！立即调度或后撤重组！" |

## 6. 验收标准

### 6.1 功能验收（必须全过）

- [ ] 布阵：开局3s倒计时内**点哪移哪**——点到兵群即选中（高亮），拖到目标位置松手部署，可多次调整，倒计时结束开战
- [ ] 移动指令：拖到目标点有箭头预览，松手执行，兵到达指定点
- [ ] 自动集火：静止步枪兵自动选择射程内最近的普通僵尸，子弹轨迹命中后结算伤害
- [ ] 战斗：步枪兵自动索敌射击，僵尸移动攻击，双方HP正常结算
- [ ] 波次：3波按配置刷新，波间横幅提示
- [ ] 破门：越过防线触发一次视觉警告，进入近身范围后按间隔扣血
- [ ] 结算：人类归零→僵尸占领；僵尸归零→防线守住；显示用时/人类存活/僵尸剩余（简单版，无指挥评分）

### 6.2 数值验收（对照原作基线）

| 项 | 原作基线 | 验收口径 |
|---|---|---|
| 前两波人类损失 | 0 | 挂机时第1、2波人类无损（允许±2） |
| 崩盘起始 | ~29s | 挂机时人类首次减员在 25~35s 区间 |
| 人类全灭 | ~42s | 挂机时 38~50s 内人类清零 |
| 第3波剩余僵尸 | ~90 | 全场追击校准实测57；确定性回归锁定57（非原作 OCR 的 90） |
| 指挥增益 | — | 熟练指挥后可守住3波；无损通关为最高成就 |

### 6.3 手感验收（主观，≥3人试玩）

- [ ] 点哪移哪跟手、误触率低（布阵点击与拖拽区分明确）
- [ ] 移动指令在紧张时（僵尸贴脸）仍可快速下达
- [ ] 竖屏单手可操作，UI 不遮挡战场关键区

## 8. 测试流程建议

1. 先跑 **挂机测试**（不指挥）：对照 §6.2 基线，校准数值；
2. 再跑 **指挥测试**（开发自测）：确认布阵（点哪移哪）/调度无阻塞；
3. 最后 **真人试玩**：收集 §6.3 手感反馈，重点看误触与紧张时刻操作效率。


## MVP follow-up：当前规则与校准

A/B/C、左中右仅为出生区域和统计标签，不是固定路径。僵尸出生即在全场选择最近存活士兵，每个 50ms 逻辑步重新决策，同距按稳定 ID；无障碍空间内直线追击，未实现 A*、导航网格或绕墙。距离 <=28px 即可近战，防线 y=1200 只记录首次跨线警告，不是伤害门槛，也不改变速度、伤害或防御；追击可返回线上方。

当前配置采用 probe3 的完整配对：僵尸速度 **41.9px/s**、攻击间隔 **0.13s**。间隔从 0.25→0.13s 是现有参数的平衡校准，不是新增机制；50ms 固定步上累计攻击时间，单步最多一次。HP40、单次伤害10、步枪HP100/伤害10/射程400/间隔0.5s/速度120、弹速900/寿命0.35s 均未改；九列5px出生布局、50人、350僵尸和0/7/20s波次保留。

当前实测：挂机种子1..10首次减员 **25.7s**，**49.55s失败，0人/57僵尸**；指挥 **53.85s** 首次减员，**74.85s胜利，4人/0僵尸**。使用六条正常群体命令：战斗24s按A/B/C当前活兵质心选择，分别到(180,1550)/(540,1550)/(900,1550)；35s重新捕获当前活兵质心与ID，再分别到(180,1750)/(540,1750)/(900,1750)。两阶段实际选择17/17/16人；没有隐藏加伤、增兵或特殊胜利。旧30.30s/47.75s/69与78.30s/3仅为线后追击历史，当前报告已替换，不再作为当前精确预言。25..35s首次减员、38..50s挂机失败、指挥胜利且存活>0及完整快照/单位/事件分段等价仍是硬目标。

MVP强制3秒自动布阵，无跳过入口；endDeployment仅为内部测试工具。可选微信短振动已实现，同批跨线合并且至少1000ms限频；无能力/抛错/异步失败不阻断战斗，暂停后台不补播、重开重置，物理效果未验证。墙侧阴影与复杂场景经用户确认延期；不扩展其他视觉功能。卡顿策略暂保留，待用户Cocos反馈再决定。Creator导入/真实渲染/构建、手机触控/振动/FPS/内存仍待用户手测，GitHub/许可证/发布暂缓。
