> **历史设计归档**：本文描述早期 50 人测试关，保留旧测试目标和测量。现行七人队伍、走廊出生与耐久门、双倍波次见 [故事场景](10-story-scenes-design.md) 和 [验收说明](09-mvp-acceptance-and-automation.md)；不要将本文的旧坐标、人数或结果用于现版验收。

> 关卡名：`LV01_zombie_wave`（复刻测试关）
> 目的：验证核心玩法（实时指挥）手感 + 复刻原作数值节奏
> 验收：见 §6，全部通过即进入下一阶段
> 状态：**MVP 开发规格**（固定时间出怪、三路、普通僵尸、群体移动、子弹轨迹、简化破门）

## 1. 关卡目标

玩家指挥 50 名步枪兵，在 3 波尸潮（50/100/200）中守住防线。
- 新手目标：学会开局布阵（点哪移哪）、拖拽调度
- 进阶目标：无损通关
- 隐藏目标：指挥 50 兵全歼 350 僵尸（含第3波）

> 集火由 AI 自动决策，玩家不手动集火；开局强制布阵 3s。

## 3. 波次配置

| 波次 | 数量 | 分路 | 刷新时刻 | 特殊规则 |
|---|---|---|---|---|
| 第1波 | 50 | 全从中路(B) | 战斗计时0s | 教学波：提示"点到兵群→拖拽调度" |
| 第2波 | 100 | 左50 + 右50 | 战斗计时7s | 教学点：多路抉择 |
| 第3波 | 200 | 左60 + 中80 + 右60 | 战斗计时20s | 触发破门机制；全部普通僵尸 |

> 布阵倒计时结束后开始战斗计时；刷怪时刻为战斗计时 0s / 7s / 20s，不等待上一波清完。
> 开局：强制布阵 3 秒倒计时。**点哪移哪**：手指点到某处即选中该处附近的兵群，拖到目标位置/阵地松手部署，可多次调整；倒计时结束开战。

## 4. 破门机制

- 触发：任意僵尸坐标 `y >= defense_line_y`；
- 效果：触发一次破门视觉警告，僵尸继续接近步枪兵；
- 近身：与步枪兵距离 `<=28px` 后按固定攻击间隔直接扣血；
- 不做防御系数、冲击状态、额外速度、额外伤害和解除条件。

## 5. 教学引导（首局强制）

| 时机 | 引导 |
|---|---|
| 开局 | 文字气泡："手指点到兵群，拖到阵地（点哪移哪），倒计时结束开战" |
| 布阵倒计时 | 提示："剩余 X 秒，可继续调整兵力" |
| 第1波 | 提示："点到你的步枪兵，拖到目标位置" |
| 第2波 | 提示："左右都有僵尸，判断哪路更危险" |
| 第3波破门 | 红字警告："防线被突破！立即调度或后撤重组！" |

## 6. 验收标准

### 6.1 功能验收（必须全过）

- [ ] 布阵：开局3s倒计时内**点哪移哪**——点到兵群即选中（高亮），拖到目标位置松手部署，可多次调整，倒计时结束开战
- [ ] 移动指令：拖到目标点有箭头预览，松手执行，兵到达指定点
- [ ] 自动集火：静止步枪兵自动选择射程内最近的普通僵尸，子弹轨迹命中后结算伤害
- [ ] 战斗：步枪兵自动索敌射击，僵尸移动攻击，双方HP正常结算
- [ ] 波次：3波按配置刷新，波间横幅提示
- [ ] 破门：越过防线触发一次视觉警告，进入近身范围后按间隔扣血
- [ ] 结算：人类归零→僵尸占领；僵尸归零→防线守住；显示用时/人类存活/僵尸剩余（简单版，无指挥评分）

### 6.2 数值验收（对照原作基线）

| 项 | 原作基线 | 验收口径 |
|---|---|---|
| 前两波人类损失 | 0 | 挂机时第1、2波人类无损（允许±2） |
| 崩盘起始 | ~29s | 挂机时人类首次减员在 25~35s 区间 |
| 人类全灭 | ~69s | 当前屏幕外出生配置挂机在 65~72s 内人类清零 |
| 第3波剩余僵尸 | ~90 | 全场追击当前实测17；确定性回归锁定17（非原作 OCR 的 90） |
| 指挥增益 | — | 熟练指挥后可守住3波；无损通关为最高成就 |

### 6.3 手感验收（主观，≥3人试玩）

- [ ] 点哪移哪跟手、误触率低（布阵点击与拖拽区分明确）
- [ ] 移动指令在紧张时（僵尸贴脸）仍可快速下达
- [ ] 竖屏单手可操作，UI 不遮挡战场关键区

## 8. 测试流程建议

1. 先跑 **挂机测试**（不指挥）：对照 §6.2 基线，校准数值；
2. 再跑 **指挥测试**（开发自测）：确认布阵（点哪移哪）/调度无阻塞；
3. 最后 **真人试玩**：收集 §6.3 手感反馈，重点看误触与紧张时刻操作效率。
