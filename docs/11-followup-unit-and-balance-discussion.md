# 后续版本兵种、尸群与结算开发讨论稿

> 状态：讨论稿，暂不修改战斗代码、配置和既有验收口径。本文把本轮提出的 7 项需求拆成可实现的产品与技术决策，作为下一轮确认和拆任务的依据。
>
> 已确认的前置决定：小队从 7 人扩为 9 人；新增 1 名狙击兵和 1 名工兵；工兵架设机枪后固定，拆卸完成后才能移动；巨胃丧尸死亡时释放胃内尚未抛出的丧尸；狙击兵特殊丧尸优先、无特殊目标时按距离最近选择、可穿透实体和巨胃本体但不可穿透墙门；盾牌对直接命中减伤；工兵机枪自动瞄准且攻击力低；特殊丧尸只在楼下地图出现；结算按兵种聚合，仅显示击杀数和实际伤害。

## 1. 版本范围与共同原则

### 1.1 目标

本轮扩展同时解决四类问题：

1. 结算可读性：玩家能看到每个兵种的击杀数和实际伤害。
2. 火力层次：新增慢速、高伤、穿透的狙击兵，以及需要选址和管理过热的工兵机枪。
3. 群体表现：盾兵更像前排，僵尸形成尸潮和堆叠；士兵仍保持可控的互斥和编队。
4. 关卡压力：楼下增加生成吞吐量，小屋减少室内生成；特殊丧尸形成新的处理优先级。

### 1.2 不变的核心边界

- `CombatSystem` 仍是伤害、死亡和击杀归属的唯一权威；表现层只消费事件。
- 伤害统计使用实际扣除的 HP，而不是攻击面板值。最后一击只计剩余 HP，过量伤害不计入统计。
- 统计按“造成致命伤害的单位”归属击杀；范围伤害每个目标分别结算。
- 被吞入胃中的丧尸从战场暂存，不算死亡、不算击杀；释放后恢复为可攻击的原单位。
- 终局时冻结统计快照；重开清零，跨场景不继承本局击杀统计。

## 2. 结算统计设计

### 2.1 展示内容

结算页增加“兵种战绩”表，每一行按兵种类型汇总：

| 字段 | 说明 |
|---|---|
| 兵种 | 步枪兵、喷火兵、盾兵、狙击兵、工兵机枪 |
| 存活数 | 该兵种进入本局的数量、终局存活数量 |
| 击杀数 | 由该兵种造成致命伤害的丧尸数量 |
| 伤害 | 该兵种对丧尸实际扣除的 HP 总和 |
| 其他指标 | 首版不显示命中次数、过热次数等额外统计 |

建议默认显示所有上场兵种，即使某兵种为 0 击杀也保留一行，避免玩家误以为该兵种没有部署。结算只显示兵种聚合，不展开具体士兵个人战绩。工兵的伤害和击杀归属给“工兵机枪”，架设、拆卸、过热时间可以作为第二行小字或详情弹层，不混入普通工兵空手攻击。

### 2.2 事件与数据结构建议

`DamageEventData` 增加 `appliedAmount`（实际扣血）和可选 `damageKind`；`unit_died` 增加 `killerId`、`killerUnitType`。统计器在核心内维护：

```ts
interface CombatStat {
  unitType: HumanUnitType;
  spawned: number;
  aliveAtEnd: number;
  kills: number;
  damage: number;
}
```

建议同时保存按运行时单位 ID 的内部统计，再按兵种聚合。这样能处理转化、召唤、释放和同兵种多个单位，不依赖事件顺序猜测归属。`unit_infected` 后，原人类单位不再继续获得人类统计；此前已造成的伤害和击杀保持原归属。

### 2.3 验收标准

- 过量伤害不超过目标死亡前 HP。
- 喷火一次命中多个目标时，每个目标分别产生实际伤害；多个目标死亡时击杀分别归属喷火兵。
- 巨胃吞入、释放不产生击杀事件；自爆丧尸死亡的击杀归属给触发投掷的巨胃丧尸，若自爆伤害杀死多个士兵/丧尸，按目标分别记录。
- 终局结算数字与事件重放结果一致；刷新 HUD、暂停或重开不改变统计。

## 3. 9 人小队与新增兵种

### 3.1 推荐初始编成

保留原 7 人并增加：4 步枪兵、2 喷火兵、1 盾兵、1 狙击兵、1 工兵，共 9 人。该编成同时保留近中远火力、前排保护和阵地火力，不需要让玩家在新增兵种出现时牺牲原有功能。

需要同步调整：`MAX_HUMANS=9`、部署编队半径、选择半径内的密集点击规则、HUD 人数、初始队伍测试和所有“7 人”文案。战斗场地不自动扩大；9 人会使位置管理和盾兵保护范围成为重要决策。

### 3.2 狙击兵 sniper

**定位**：远距离点杀高价值目标，穿透尸群后仍能命中后排。目标选择固定为特殊丧尸优先；当前特殊丧尸为巨胃丧尸。没有存活特殊丧尸时，按距离最近选择普通丧尸。

**推荐首版数值**：

| 属性 | 建议值 | 设计理由 |
|---|---:|---|
| HP | 85 | 后排输出，不应替代前排承伤 |
| 伤害 | 150 | 普通丧尸一枪击杀，特殊丧尸约 2–3 枪 |
| 射程 | 520 px | 明显高于步枪兵 260 px |
| 射击间隔 | 1.60 s | 慢速，给玩家观察和调位窗口 |
| 子弹速度 | 1200 px/s | 远距离仍保持响应感 |
| 穿透数量 | 3 个目标 | 首目标及其后方最多 2 个 |
| 穿透衰减 | 每穿过一个目标减少 20% | 防止一枪清空整列 |
| 口径/颜色 | 深蓝枪身、亮青弹道 | 与绿色步枪、红色喷火、浅蓝盾牌区分 |

**穿透定义**：发射时锁定方向而非只锁定一个目标；按子弹轨迹上的投影距离排序，命中轨迹半径内的存活丧尸。实体之间不阻挡狙击子弹，巨胃本体也不阻挡；墙体、关闭的大门等固定地形仍阻挡。每个目标每发最多受伤一次，伤害衰减后取整，最低 1 点。狙击兵可以穿透巨胃并继续命中其后方的丧尸，但不能隔墙或隔门射击。

**已确认取舍**：特殊丧尸优先与穿透同时启用，狙击兵承担处理巨胃的明确职责。首版固定为“特殊优先 + 3 穿透”，通过楼下特殊丧尸数量和生成时机调节压力，不引入暴击或弱点倍率。

### 3.3 工兵与架设机枪

**定位**：牺牲移动换取短时间高射速区域压制。工兵本体初始可移动，架设后进入 `Deployed`，不能接收移动命令；拆卸完成才回到可移动状态。

**推荐状态机**：

```text
Idle/Moving -> Deploying -> Deployed/Firing -> Overheated/Cooling
Deployed/Cooling -> Dismantling -> Idle
任意部署状态 -> Dead
```

| 参数 | 建议值 |
|---|---:|
| 工兵 HP | 100 |
| 架设时间 | 2.0 s |
| 拆卸时间 | 1.5 s |
| 机枪射程 | 300 px |
| 射速 | 10 发/s |
| 单发伤害 | 4 |
| 弹匣/热量上限 | 连续 3.0 s |
| 过热停顿 | 2.5 s |
| 冷却方式 | 停火后按时间恢复；未完全冷却不能重新持续扫射 |
| 子弹 | 普通单目标弹，不穿透 |

建议玩家点击工兵后点击地面进行架设，再点击已架设工兵触发拆卸；架设期间可被僵尸攻击，取消架设不返还时间。机枪自动瞄准攻击范围内的目标，优先规则沿用普通远程单位的目标排序；工兵位置固定。拆卸期间进入 `Dismantling`，不能攻击、不能重新瞄准，也不能移动；拆卸完成后才恢复可移动状态。机枪单发伤害固定为低伤害档，首版建议 4 点，主要价值是高射速压制而不是单点爆发。

**工兵过热曲线建议**：使用 0–100 的热量值。每发子弹增加 `3.3` 点热量，连续射击约 3 秒达到 100；达到 85 后进入警告区，达到 100 后立即进入 `Overheated`，停止射击并锁定 2.5 秒。过热锁定结束后进入 `Cooling`，每秒降低 45 点热量；热量降到 25 以下才允许重新进入 `Deployed/Firing`。停止射击时不立即清零，前 0.5 秒只按每秒 30 点下降，之后按每秒 45 点下降，避免玩家通过短暂松手完全规避过热。

**自动瞄准建议**：每 0.15 秒重选一次目标；只在机枪射程内、无遮挡的存活丧尸中选择距离最近者。目标离开射程、死亡或被墙遮挡时立即清除目标，但不打断当前过热和冷却计时。拆卸开始后清除目标，拆卸完成前不重新索敌。

**工程边界**：不要把机枪做成独立可被选择的士兵。机枪是工兵的武器状态，伤害归属工兵 ID；工兵死亡时机枪立即失效并清理临时弹道。

## 4. 盾兵强化

### 4.1 视觉尺寸

盾兵整体直径建议为普通人类球体的 `1.33x`：现有普通人类直径 28 px，盾兵直径改为约 37 px，半径和碰撞同步扩大，避免只放大画面导致穿模。外围盾面至少覆盖球体朝向前方的 120° 扇区，盾面半径为球体半径的 1.35–1.50 倍，保证覆盖球体约 1/3 视觉面积。

### 4.2 防护机制建议

只放大盾牌不足以形成玩法。首版增加方向减伤：来自盾面前方 120° 的直接命中伤害降低 60%，侧面和背面不减伤；喷火范围、自爆范围等范围伤害不受盾牌减伤。盾兵仍可攻击，不改为纯阻挡单位。

## 4.3 喷火兵重新校准

喷火兵当前的覆盖范围和持续伤害过强，需要从“持续大范围清场”改为“短距离、短窗口、需要收火和冷却的近区压制”。

### 推荐首版参数

| 属性 | 当前参考 | 建议值 | 说明 |
|---|---:|---:|---|
| 射程 | 190 px | 110 px | 小于步枪兵 260 px 的一半（130 px） |
| 范围半径 | 72 px | 42 px | 只覆盖火焰前端附近的小群体 |
| 单次伤害 | 24 | 14 | 每次伤害 tick，降低范围爆发 |
| 持续喷射 | 0.6 s | 0.45 s | 一次短喷，不允许长时间无脑覆盖 |
| 伤害间隔 | 0.1 s | 0.15 s | 降低单位时间范围伤害 |
| 过热上限 | 无 | 100 | 连续喷射约 2.0 秒达到上限 |
| 冷却时间 | 无 | 2.0 s 锁定 + 后续降温 | 过热后不能立即再次喷射 |
| 移动速度 | 44 px/s | 40 px/s | 保留机动性，但比普通步枪兵慢 |

### 状态和收火过程

喷火兵增加 `Firing`、`RetractingFlame`、`Overheated`、`Cooling` 状态：

```text
Idle/Aiming -> Firing -> RetractingFlame -> Idle/Aiming
Firing -> Overheated -> Cooling -> Idle/Aiming
任意可移动状态 -> Moving
Moving 时若仍有火焰：RetractingFlame -> Moving
Moving -> ReleasingFlame -> Firing
```

移动不会瞬间关闭火焰。收到移动命令后进入 `RetractingFlame`，在 0.30 秒内将火焰长度和宽度逐渐缩小到 0，同时停止伤害 tick；收火完成后才真正开始移动。到达移动目标后，若有有效目标且热量低于阈值，进入 `ReleasingFlame`，在 0.25 秒内从短火焰逐步恢复到标准长度，再开始伤害。这样移动存在明确的启动和恢复过程，速度建议保持 40 px/s，不追求瞬移，也不让收火动画拖慢到无法操作。

喷火兵移动期间不攻击；只有完成收火、移动结束并完成重新放火过程后才能继续造成范围伤害。移动命令会打断当前喷射，但不会清空热量；若热量已经达到过热阈值，则必须先完成冷却。

需要新增受击事件中的入射方向或攻击位置，不能由 HUD/UnitView 根据画面猜测。盾面朝向优先使用当前目标方向，其次使用移动方向，最后保留上一帧朝向。

## 5. 尸群堆叠与生成节奏

### 5.1 僵尸堆叠规则

当前 `CombatSystem.separateZombies` 会把普通行走中的僵尸互相推开，造成与需求相反的互斥效果。下一版应删除或关闭僵尸之间的分离推力，仅保留：

- 僵尸与墙体、门、地图边界的碰撞。
- 僵尸不能穿过不可破坏墙体。
- 僵尸在同一位置时使用稳定的目标选择和移动顺序，避免 NaN 或无限循环。
- 既有“墙边达到数量后翻越”的堆叠逻辑保留；`stackLevel` 只表达翻墙层级，不再用于普通尸群分离。

视觉层可以允许身体重叠，但应使用轻微深度排序、透明度或描边，让后排仍可识别。建议不把所有僵尸强行堆成单像素：移动碰撞半径仍用于墙体寻路，单位之间不互斥。

### 5.2 生成节奏调整

建议先改场景配置，不在 `SpawnSystem` 中硬编码。楼下放弃“按三波定量生成”的旧模型，改为持续刷怪调度器；大屋仍可保留固定波次，方便形成室内阶段性压力：

| 场景 | 当前总数 | 讨论稿总数 | 批次 | 批间隔 | 方向 |
|---|---:|---:|---:|---:|---|
| 大屋 | 700 | 450–550 | 15 | 0.35 s | 室内减少，保留三波压力 |
| 楼下 | 270 | 720 的持续生成上限/目标量 | 不按波 | 持续间隔 | 四边持续出现，形成开放区域尸潮 |

建议初始试验值：大屋 `500`，楼下累计生成目标 `720`。大屋波次开始时间可暂保持不变，避免同时改时间轴导致无法定位难度变化。楼下不再等待波次时间，也不把 720 只拆成三组；战斗开始后按持续调度器不断生成，直到达到 720 或关卡终局。推荐基础生成间隔 0.35 秒，每次 10–20 只，按北/南各 30%、东/西各 20% 分摊，并在任一路线拥堵时动态转移到其他出生点。特殊丧尸只配置在楼下地图，不出现在大屋。

**吞吐量约束**：楼下 720 只持续生成时，不能再用“波次已生成”判断胜利，必须由持续调度器明确 `generationComplete`。建议先用 0.35 秒基础间隔、单批 10 只作为稳定基线，再根据活动单位峰值调整到 0.25–0.5 秒；生成数量增加不应通过降低碰撞检查精度来换取性能。终局条件应是持续调度器达到 720 且场上无存活僵尸。

## 6. 巨胃丧尸（建议 ID：`gut_zombie`）

### 6.1 行为循环

1. 出场时寻找半径 180 px 内最多 5 只普通丧尸；按距离从近到远吞入。
2. 被吞入的丧尸从 `UnitStore` 的活动战场隐藏，状态为 `StoredInGut`，不计存活敌人数、不参与寻路、不产生死亡或击杀事件。
3. 巨胃受到任意有效伤害后，若胃内有丧尸，则向攻击者方向抛出 1 只；抛出物落地后进入 `Suicidal`，短暂追向落点附近敌人并自爆。
4. 自爆造成一次范围伤害，建议半径 72 px、对人类 60 点、对丧尸 30 点；自爆丧尸随后死亡。
5. 巨胃每次受击最多触发一次抛掷，触发冷却建议 1.2 s；没有胃内容物时只承受伤害。
6. 巨胃死亡时释放胃中剩余丧尸，释放物恢复其原 `normal_zombie` 类型和完整 HP，出生点为巨胃当前位置周围的稳定扇形位置。

### 6.2 推荐初值

| 属性 | 建议值 |
|---|---:|
| HP | 300 |
| 直径 | 56 px |
| 移速 | 22 px/s |
| 吞入半径 | 180 px |
| 最大储存 | 5 |
| 受击抛掷冷却 | 1.2 s |
| 自爆延迟 | 0.8 s |
| 自爆半径 | 72 px |
| 自爆伤害 | 人类 60 / 僵尸 30 |

“上场时”建议解释为生成后立即尝试吞入，而不是生成前从远处瞬间删除；若出生点附近不足 5 只，则只吞入实际存在的数量。吞入的丧尸必须保留原 ID 或可追踪来源，以便释放和统计回放。

### 6.3 归属和反制

- 巨胃吞入不会计为任何士兵击杀。
- 自爆丧尸不是士兵直接击杀；若其自爆死亡，记为巨胃特殊伤害，不记入狙击兵/工兵等普通攻击击杀。
- 推荐允许玩家优先击杀巨胃，释放全部剩余丧尸，形成“现在处理巨胃还是先清外围”的选择。
- 巨胃不能吞入特殊丧尸、正在攀爬或已被其他技能锁定的丧尸，首版仅吞 `normal_zombie`。

## 7. 推荐实现顺序

1. 先做结算统计和 9 人编制，建立可观测基线。
2. 修正僵尸分离逻辑，补充尸群重叠回归测试。
3. 加入狙击兵和穿透弹，再调特殊目标优先级。
4. 加入盾兵碰撞尺寸和方向减伤。
5. 加入工兵架设/拆卸/过热状态及机枪弹道。
6. 加入巨胃吞入、抛掷、自爆、死亡释放。
7. 最后调整小屋/楼下生成量，分别跑挂机、固定微操和设备性能测试。

每一步都应保持旧兵种可单独运行；新增特殊单位需要专门测试，不把整局偶然胜负作为唯一验收标准。
