## 玩法与性能限制

当前只有一张三路地图、两类单位和固定波次；无精英、随机事件、成长存档、音频、镜头移动/缩放、联网或主菜单。跨路人类移动是直线、墙不阻挡；routeId 保持出生归属，不代表实时所在路。seed 不参与随机计算。未把设计文档中的后期玩法视为已实现。

controller 单帧最多推进 50ms，长卡顿丢失墙钟进度；BattleSession/core 的 elapsed 分段等价不改变此策略。完整事件历史仅在本局保留，重启清理；无限关卡和长会话不是已验证用途。每帧单位副本、Graphics 几何重建和逐攻击者最近目标扫描仍需真实分析。

统计是被动观测：FPS 用单调墙钟窗口，presentationMs 只测适配层提交；command feedback 不是 touch-to-photon。20 局放置失败回归不能证明 64 同屏弹道峰值、全树稳定、JS/native/GPU 内存或持续真机帧率。
