## 1. 设计总则

| 原则 | 说明 |
|---|---|
| 极简 | 所有单位=圆点，不做骨骼/动画帧，用颜色+大小+状态圈表达信息 |
| 柔和亮色 | 颜色取"中等饱和度 + 高亮度"，避免过艳刺眼，弱光下依然清晰 |
| 透亮发光 | 单位用双层绘制（外光晕+内亮芯），半透明叠加不显脏，保持透亮感 |
| 统一 | 同一阵营所有单位共用色系；兵种差异用色相/大小/描边区分 |

## 2. 全局色板

| 元素 | 颜色 | HEX | 用途 |
|---|---|---|---|
| 背景板 | 纯黑（近黑） | `#0B0B0F` | 战场底色 |
| 墙面/掩体 | 柔和灰 | `#7A7A85` | 通道、掩体、防线段 |
| 墙面暗部 | 深灰 | `#3F3F48` | 墙面阴影/厚度 |
| 人类主色 | 柔和亮绿 | `#63D68F` | 步枪兵 |
| 僵尸主色 | 柔和亮紫 | `#9F8BE8` | 普通僵尸 |
| 破门警告 | 柔和亮玫红 | `#E06E88` | 防线突破视觉警告；精英单位留待后期 |
| 指令/选中 | 柔和亮青 | `#6ED4DB` | 选中、指令箭头 |
| 提示文字 | 白 | `#F2F2F7` | HUD文字 |

> 色彩策略：主色取 `饱和度 60~75%、明度 75~85%`——比纯高饱和更柔和耐看，又在黑底上保持清晰发光感；避免 100% 饱和度的刺眼纯色。颜色名统一用"柔和亮X"命名。

## 3. 单位造型规范（统一模板）

所有单位统一按以下模板设计，兵种差异只改参数：

| 字段 | 规则 |
|---|---|
| 造型 | 正圆形（Canvas `arc` 填充），**双层绘制** |
| 直径 | 人类 14px；普通僵尸 16px，相对 1080px 设计宽 |
| 内层亮芯 | 主色填充，不透明度 65~75%，为视觉主体 |
| 外层光晕 | 同主色，半径×1.5，不透明度 18~25%，营造发光透亮感 |
| 描边 | 无（选中时加亮青描边圈，2px） |
| 状态圈 | 选中=亮青环；AI集火目标=白色准星线指示；移动中=脚下方向箭头 |
| 死亡 | 缩小淡出（0.3s），不残留尸体（降低视觉噪点） |

**透亮实现（关键）**：单位不是"纯色+低透明度"，而是「外层光晕 + 内层亮芯」双层结构——光晕负责通透发光感，亮芯保证单只可辨；重叠时两两光晕叠加自然提亮，形成明亮通透的"色块军团"，不会因降低透明度而发灰发脏。选中高亮时亮芯临时提升至 90%。

## 4. 战场元素设计

| 元素 | 设计 | 说明 |
|---|---|---|
| 背景 | `#0B0B0F` 纯色 + 极淡网格（5%白，128px格） | 提供移动参考感 |
| 墙面 | 灰 `#7A7A85` 矩形块，顶面亮、侧面深灰 | 分隔路线，阻挡单位 |
| 刷怪口 | 灰墙缺口 + 紫光晕（`#9F8BE8` 20%透明度扩散） | 预告僵尸出生方向 |
| 防线段 | 灰色虚线（破门时变红闪+抖动） | 破门机制可视化 |
| 出生区 | 上方区域顶部 20% 深黑渐隐 | 暗示"尸潮来自上方" |

## 5. 指令视觉：移动方向箭头（重点）

移动指令是核心操作，箭头承担"标明移动方向"职责，规范如下：

| 字段 | 规范 |
|---|---|
| 形态 | 虚线路径 + 端点箭头（`起点 ─ ─ ▷ 目标点`） |
| 颜色 | 指令青 `#6ED4DB`，线宽 2px |
| 虚线 | 段长 6px / 空隙 4px，路径跟随手指拖拽实时弯曲 |
| 端点箭头 | 实心三角，边长 12px，**尖端明确指向目标点** |
| 预览 | 拖拽中实时显示"起点→当前点"路径，松手执行 |
| 取消 | 拖回起点（或原路退回）即取消，箭头淡出 |
| 移动中反馈 | 兵团脚下持续显示同色小箭头（8px），朝行进方向，到达目标后消失 |
| AI集火指示 | 白色准星线指向 AI 选定的集火目标（仅指示，不可点；区别于移动箭头） |

**设计要点**：箭头尖永远是"接下来要去哪"的唯一视觉锚点——路径弯曲度、箭头朝向随手指实时变化，让玩家指尖所见即指令所达；禁止在箭头旁堆叠多余图标。

## 6. HUD 视觉规范

| 元素 | 规范 |
|---|---|
| 顶部标题 | 白字 20px 粗体，左右阵营名用各自主色 |
| 底部信息条 | 半透明黑底（70%）圆角，内边距 12px |
| 数量进度条 | 左侧人类绿条 vs 右侧僵尸紫条，中间对比线 |
| 波次横幅 | 全屏居中大字（白描边）+ 缩放弹入动画 |
| 按钮 | 半透明深底 + 主色描边，按下高亮；拇指热区 ≥88px |
| 结算面板 | 全屏半透明黑遮罩 + 居中卡片（黑底白字），显示用时/存活/剩余 |
