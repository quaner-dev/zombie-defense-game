# 地图设计：LV01 左中右三路（MVP v1.0）

> 关卡：`LV01_zombie_wave`
> 用途：定义地图空间、路线、出生点、防线和兵群可移动区域。
> MVP 范围：固定一张竖屏地图，左/中/右三个出生区域；不做动态地形和复杂障碍。

## 1. 地图目标

- 地图必须让玩家在同一屏内看清三个出生区域、三处主要防守点和防线位置。僵尸从屏幕上方外侧进入，不在画面内显示出生标记；玩家的核心决策包括跨路增援与本路后撤重组。

## 2. 坐标与适配

- 逻辑设计尺寸：`1080 × 2400`；手机预览例如 `393 × 852` 由 Cocos 按设计分辨率等比适配，不把手机像素直接当作战斗坐标。
- 原点：左上角；`x` 向右增加，`y` 向下增加。
- 士兵可移动战场区：`x=60..1020`、`y=180..2160`；僵尸出生区额外允许 `y=-180..0`，用于从屏幕外进入。
- HUD 区域不参与单位移动：顶部 `0..180`，底部 `2160..2400`。
- Cocos 使用设计分辨率适配；逻辑坐标通过地图坐标转换为屏幕坐标。
- MVP 不允许缩放和平移镜头，完整战场保持在可视区域内。

## 3. 路线定义

| 路线 | 出生点 | 防守点 | 出生坐标 | 防守坐标 | 防线位置 |
|---|---|---|---|---|---|
| 左路 A | `spawn_A` | `defend_A` | `(180, -40)` | `(180, 1370)` | `y=1200` |
| 中路 B | `spawn_B` | `defend_B` | `(540, -40)` | `(540, 1370)` | `y=1200` |
| 右路 C | `spawn_C` | `defend_C` | `(900, -40)` | `(900, 1370)` | `y=1200` |

- 每条路线默认宽度：`240px`。
- 区域中心仅用于出生布局和统计；不限制索敌或追击。
- 步枪兵可以在战场区内自由移动，但移动目标会被限制在 `x=60..1020`、`y=180..2160`。
- MVP 不实现路线之间的自动寻路；兵群移动使用直线插值，地图障碍暂不阻挡。
- 三个出生区域之间不共享僵尸出生点；出生点位于屏幕外，不渲染紫色标记；步枪兵可以跨路增援。
- 战斗计时从 3 秒布阵倒计时结束后开始；地图只保存空间定义，不保存波次时间。

## 4. 防线与破门

- 防线为横向逻辑线：`y=1200`。
- 僵尸 `y >= 1200` 即视为越过防线。
- 从出生即追击全场最近士兵，是否过线不影响攻击。
- MVP 不设置防御系数、冲击状态、速度加成或破门计时。
- 首次跨线只负责警告和可选限频振动，不授予攻击能力。

## 5. 玩家布阵

- 当前默认兵力为 15 名人类士兵，按 A/B/C 三路分配；兵种由当前配置权重生成。
- 开局布阵持续 3 秒。
- 玩家点击或拖动某个士兵时，系统在固定选择半径内选择距离最近的一名存活士兵。
- 松手后，只有这名士兵移动到目标点附近。
- MVP 不实现空白处框选、不实现多选、不实现双指缩放和地图平移。
- 选择半径默认 `112px`；目标点落在战场边界外时夹到最近边界。

## 6. 地图配置示例

```json
{
  "map_id": "LV01_three_routes",
  "design_size": { "width": 1080, "height": 2400 },
  "battle_bounds": { "left": 60, "top": 180, "right": 1020, "bottom": 2160 },
  "spawn_bounds": { "top": -180 },
  "routes": {
    "A": { "spawn": { "x": 180, "y": -40 }, "defend": { "x": 180, "y": 1370 }, "width": 240 },
    "B": { "spawn": { "x": 540, "y": -40 }, "defend": { "x": 540, "y": 1370 }, "width": 240 },
    "C": { "spawn": { "x": 900, "y": -40 }, "defend": { "x": 900, "y": 1370 }, "width": 240 }
  },
  "defense_line_y": 1200,
  "unit_selection_radius": 72,
  "spawn_layout": { "columns": 9, "spacing_px": 5 }
}
```

## 7. 后期扩展约束

- 新地图只新增地图配置和场景资源，不修改 `CombatSystem` 的攻击结算接口。
- 路线 ID 使用稳定字符串，波次配置只引用路线 ID。
- 后续需要障碍物时新增 `obstacles` 和寻路策略，不改变现有出生点、防线和单位接口。

## MVP follow-up：当前规则与校准

A/B/C、左中右仅为出生区域和统计标签，不是固定路径。僵尸出生即在全场选择最近存活士兵，每个 50ms 逻辑步重新决策，同距按稳定 ID；无障碍空间内直线追击，未实现 A*、导航网格或绕墙。距离 <=28px 即可近战，防线 y=1200 只记录首次跨线警告，不是伤害门槛，也不改变速度、伤害或防御；追击可返回线上方。

当前配置最多15名士兵，普通僵尸60HP、速度41.9px/s、攻击间隔0.13s；步枪单发30点伤害、260px射程、0.35s间隔。士兵与僵尸显示直径分别为28px和32px，边缘出生按每批5只、每秒一批进入；三波宣告时间为0/7/20s、总量350只，波次之间保留已在场士兵。

旧出生点和50名士兵的历史实测仅作参考；当前自动化挂机在79.95s胜利并保留15名士兵，开局单兵微操在108.85s胜利并保留14名士兵。正式结果以当前配置重新生成的验收报告为准。

MVP强制3秒自动布阵，无跳过入口；endDeployment仅为内部测试工具。可选微信短振动已实现，同批跨线合并且至少1000ms限频；无能力/抛错/异步失败不阻断战斗，暂停后台不补播、重开重置，物理效果未验证。墙侧阴影与复杂场景经用户确认延期；不扩展其他视觉功能。卡顿策略暂保留，待用户Cocos反馈再决定。Creator导入/真实渲染/构建、手机触控/振动/FPS/内存仍待用户手测，GitHub/许可证/发布暂缓。
