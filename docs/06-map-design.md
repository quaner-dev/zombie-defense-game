# 地图设计：LV01 左中右三路（MVP v1.0）

> 关卡：`LV01_zombie_wave`
> 用途：定义地图空间、路线、出生点、防线和兵群可移动区域。
> MVP 范围：固定一张竖屏地图，左/中/右三条路线；不做动态地形和复杂障碍。

## 1. 地图目标

地图必须让玩家在同一屏内看清三条路线、三处出生点、三处主要防守点和防线位置。玩家的核心决策是把兵群从安全路线调到正在承受压力的路线。

## 2. 坐标与适配

- 逻辑设计尺寸：`1080 × 2400`。
- 原点：左上角；`x` 向右增加，`y` 向下增加。
- 战场逻辑区：`x=60..1020`、`y=180..2160`。
- HUD 区域不参与单位移动：顶部 `0..180`，底部 `2160..2400`。
- Cocos 使用设计分辨率适配；逻辑坐标通过地图坐标转换为屏幕坐标。
- MVP 不允许缩放和平移镜头，完整战场保持在可视区域内。

## 3. 路线定义

| 路线 | 出生点 | 防守点 | 出生坐标 | 防守坐标 | 防线位置 |
|---|---|---|---|---|---|
| 左路 A | `spawn_A` | `defend_A` | `(180, 260)` | `(180, 1370)` | `y=1200` |
| 中路 B | `spawn_B` | `defend_B` | `(540, 260)` | `(540, 1370)` | `y=1200` |
| 右路 C | `spawn_C` | `defend_C` | `(900, 260)` | `(900, 1370)` | `y=1200` |

- 每条路线默认宽度：`240px`。
- 路线中心线用于僵尸寻路和路线归属判断。
- 步枪兵可以在战场区内自由移动，但移动目标会被限制在 `x=60..1020`、`y=240..2100`。
- MVP 不实现路线之间的自动寻路；兵群移动使用直线插值，地图障碍暂不阻挡。
- 三条路线之间不共享僵尸出生点，但步枪兵可以跨路增援。
- 战斗计时从 3 秒布阵倒计时结束后开始；地图只保存空间定义，不保存波次时间。

## 4. 防线与破门

- 防线为横向逻辑线：`y=1200`。
- 僵尸 `y >= 1200` 即视为越过防线。
- 越过防线后，僵尸继续移动到最近的步枪兵近身攻击范围。
- MVP 不设置防御系数、冲击状态、速度加成或破门计时。
- 防线越过事件只负责触发一次视觉警告和允许近身攻击。

## 5. 玩家布阵

- 初始兵力为 50 名步枪兵，默认分布为左/中/右 `17/17/16`。
- 开局布阵持续 3 秒。
- 玩家点击或拖动某个兵群时，系统选择该位置附近的整个兵群，不选择单个士兵。
- 松手后，选中的兵群整体移动到目标点。
- MVP 不实现空白处框选、不实现单兵选择、不实现双指缩放和地图平移。
- 兵群的选择半径默认 `72px`；目标点落在战场边界外时夹到最近边界。

## 6. 地图配置示例

```json
{
  "map_id": "LV01_three_routes",
  "design_size": { "width": 1080, "height": 2400 },
  "battle_bounds": { "left": 60, "top": 180, "right": 1020, "bottom": 2160 },
  "routes": {
    "A": { "spawn": { "x": 180, "y": 260 }, "defend": { "x": 180, "y": 1370 }, "width": 240 },
    "B": { "spawn": { "x": 540, "y": 260 }, "defend": { "x": 540, "y": 1370 }, "width": 240 },
    "C": { "spawn": { "x": 900, "y": 260 }, "defend": { "x": 900, "y": 1370 }, "width": 240 }
  },
  "defense_line_y": 1200,
  "unit_selection_radius": 72
}
```

## 7. 后期扩展约束

- 新地图只新增地图配置和场景资源，不修改 `CombatSystem` 的攻击结算接口。
- 路线 ID 使用稳定字符串，波次配置只引用路线 ID。
- 后续需要障碍物时新增 `obstacles` 和寻路策略，不改变现有出生点、防线和单位接口。
