# Zombie Defense · 三路僵尸防守

实时群体指挥游戏 MVP：50 名步枪兵面对三路、三波共 350 只普通僵尸，玩家拖拽调动兵群。独立 TypeScript 核心负责战斗规则，Cocos Creator 3.8.8 适配层负责输入、Graphics 绘制与 HUD。

**当前是已做无渲染验证的核心与已编写的 Cocos 场景适配层。Creator 导入、预览、Web Mobile/微信构建及真机性能尚未验证，不能视为可发布版本。**

## 快速开始

准备独立安装的 **Node.js v26.7.0** 和 npm（本次文档核对环境为 npm 11.19.0）。v26.7.0 是已有执行证据使用的版本；项目尚无 `engines` 约束或版本矩阵，不宣称 Node 20/22 或其他版本兼容。Creator 自带 Node 不替代此前置条件。

在完整源码根目录执行：

```sh
npm ci
npm run sync:core
npm test
npm run typecheck
npm run typecheck:cocos
npm run check:cocos-bundle
```

这些命令不会启动游戏画面。`npm test` 自动同步生成核心；bundle 检查**不是引擎构建**。可视运行请按 [上手与使用](docs/getting-started.md) 安装 Creator 3.8.8，导入 `assets/scenes/Battle.scene`。完整测试含 20 局重启回归和临时源码副本的真实依赖安装，耗时较长且需要网络。

## 当前规则与证据

3秒布阵结束才启动战斗钟，无跳过入口；波次在0/7/20s触发，不等待清场。A/B/C是出生区域与统计标签，僵尸从出生即全场最近索敌并直线追击，28px内按间隔攻击；防线仅警告，不是伤害门槛或移动屏障。士兵移动时停火；全灭失败优先。50ms固定步进保留未完成余量，无复杂绕障。

当前配置：步枪射程400px，僵尸速度41.9px/s、攻击间隔0.13s，九列5px出生布局。0.25→0.13s是现有参数校准，不是新机制，HP40和伤害10未改。

| 场景 | 首次人类减员 | 终局战斗时间 | 终局 |
|---|---:|---:|---|
| 挂机，种子1–10 | 25.7s | 49.55s | 失败，0人 / 57僵尸 |
| 24s/35s两阶段各A/B/C后撤，共六命令 | 53.85s | 74.85s | 胜利，4人 / 0僵尸 |

24s分别到(180,1550)/(540,1550)/(900,1550)，35s重新按活兵当前质心捕获ID到各自x、y1750；每阶段17/17/16。没有隐藏伤害或特殊胜利。[JSON报告](docs/testing/mvp-test-report.json)替换旧30.30s/47.75s/69及78.30s/3历史测量；seed当前不影响随机战斗。硬目标25..35s/38..50s、挂机失败、指挥胜利存活及完整状态/事件分段等价未放宽。

可选微信破门短振动已实现，同批合并、1000ms限频，物理效果未验证。墙侧阴影和复杂场景确认延期；卡顿策略待Cocos反馈，GitHub/许可证/发布暂缓。[用户Cocos手测清单与模板](docs/testing/cocos-manual-checklist.md)用于后续记录，自动化通过不等于平台验收。实际测试计数及检查结果见本轮Task3/4交付报告；旧99项记录不代表当前套件。
