# Zombie Defense · 四向僵尸防守

实时群体指挥游戏：50 名步枪兵面对三波共 350 只普通僵尸，僵尸从地图四边进入，玩家用手指固定范围选兵并拖拽微操。独立 TypeScript 核心负责战斗规则，Cocos Creator 3.8.8 适配层负责输入、Graphics 绘制与 HUD。

**当前是已做无渲染验证的核心与已编写的 Cocos 场景适配层。Creator 导入、预览、Web Mobile/微信构建及真机性能尚未验证，不能视为可发布版本。**

## 快速开始

准备独立安装的 **Node.js v26.8.1** 和 npm。v26.8.1 是本轮执行验证使用的版本；项目尚无 `engines` 约束或版本矩阵，不宣称 Node 20/22 或其他版本兼容。Creator 自带 Node 不替代此前置条件。

在完整源码根目录执行：

```sh
npm ci
npm run sync:core
npm test
npm run typecheck
npm run typecheck:cocos
npm run check:cocos-bundle
```

这些命令不会启动游戏画面。`npm test` 自动同步生成核心；bundle 检查**不是引擎构建**。可视运行请按 [上手与使用](docs/getting-started.md) 安装 Creator 3.8.8，导入 `assets/scenes/Battle.scene`。完整测试含 20 局重启回归和临时源码副本的真实依赖安装，耗时较长且需要网络。

## 当前规则与证据

3秒布阵结束才启动战斗钟，无跳过入口；波次在0/7/20s触发，不等待清场。A/B/C是步枪兵分组与僵尸统计标签，僵尸从北、南、东、西边缘进入并全场最近索敌，28px内按间隔攻击。僵尸可绕墙追击，墙边同一堆达到3只仍可翻墙；翻墙期间不受分离推力干扰，落地后恢复最小间距分离。每次按下仅选中112px圆内士兵，不沿用原整组选中或矩形框选；各自向松手点附近靠拢，移动时停火。全灭失败优先。50ms固定步进。

当前配置：步枪射程260px，士兵速度48px/s，略快于僵尸的41.9px/s；步枪每0.35s一发，僵尸60HP、攻击间隔0.13s。射击须同时满足距离和墙体遮挡判断，飞行途中碰墙即停止，目标中途躲到墙后也不会扣血；拖拽时显示固定选择圆与一名士兵的射程参考圈。枪口闪光、飞行亮线与弹头显示射击方向，命中弹道保留0.10s，近距离也可见；墙面火花在实际接触处结束。

当前四向地图的整局验收使用挂机与开局收拢两种场景，实测结果见 [JSON报告](docs/testing/mvp-test-report.json)。开局收拢在战斗0s按三组活兵质心捕获ID，依次拖到墙下方空地(450,1400)/(540,1400)/(630,1400)；每条命令均核对实际选中ID。旧版落点(380,1200)/(700,1200)在墙内，不再用于集结。当前实测挂机56.85s失败、剩30只僵尸，收拢战术48.3s胜利、存活42人。seed当前不影响随机战斗；种子1–10结果一致，完整状态/事件在不同帧分段下等价。

可选微信破门短振动已实现，同批合并、1000ms限频，物理效果未验证。墙侧阴影和复杂场景确认延期；卡顿策略待Cocos反馈，GitHub/许可证/发布暂缓。[用户Cocos手测清单与模板](docs/testing/cocos-manual-checklist.md)用于后续记录，自动化通过不等于平台验收。实际测试计数及检查结果见本轮Task3/4交付报告；旧99项记录不代表当前套件。
